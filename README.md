🐶 DOG BREEDS EXPLORER 🦴

About the Project 💡

This is a simple application built primarily to practice and understand the end-to-end implementation of fetching data using a REST API from thedogapi.com and displaying it on the frontend. The main focus is learning how to connect a frontend interface to a backend data source, managing state, and handling asynchronous requests in a modern development environment.

🚀 Setup & Run

Prerequisites

To get the application running, ensure you have the following installed:

Node.js (LTS version recommended)

A package manager (npm or yarn).

⚙️ Installation

Clone the Repository:

git clone [https://github.com/devrainyel/dog-breeds-explorer.git](https://github.com/devrainyel/dog-breeds-explorer.git)
cd dog-breeds-explorer


Install Dependencies:
Run this command in the root directory to install dependencies for both the client and server:

npm install
# or
yarn install


▶️ Running the Application

Since this project separates the client (frontend) and server (backend) logic, you will need two separate terminal windows open to run both parts concurrently.

Terminal 1: Start the Client (Frontend)

cd client
npm run dev


Terminal 2: Start the Server (Backend)

cd server
npm run dev


The application will typically be accessible in your browser at http://localhost:3000 (or the port specified by your client framework).

🛠 Core Concepts Explored

This project was a practical exercise in:

API Implementation: Consuming and handling data from an external REST API (thedogapi.com).

Frontend Framework: Building a component-based UI using React.

Styling: Implementing modern, responsive design using Tailwind CSS.
